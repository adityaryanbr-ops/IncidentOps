# IncidentOps frontend

Next.js workspace for IncidentOps. Install steps, ports, and environment variables are in the repository root [README](../README.md).

From this folder, after `npm install` and copying `.env.example` to `.env.local`:

```bash
npm run dev
```

The dev server listens on [http://127.0.0.1:3847](http://127.0.0.1:3847) and calls the API at `http://127.0.0.1:8765`.
